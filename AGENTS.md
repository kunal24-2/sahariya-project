# Agents Configuration – BrightMind Project

## Project Name
BrightMind – Mental Wellness Website

## Project Description
BrightMind is a static, front-end mental wellness website built using HTML and CSS.
The project focuses on calm, accessible, and visually engaging design principles
inspired by color psychology to promote mental well-being.

## Important Rule
This project DOES NOT include any emojis.
All content, UI elements, documentation, and future contributions must avoid emojis entirely.

## AI / Agent Usage Policy
AI agents may be used for:
- UI/UX improvements
- Accessibility enhancements
- Code refactoring
- Performance optimization
- Documentation writing
- Content clarity and tone refinement

AI agents must NOT:
- Introduce emojis into any part of the project
- Add JavaScript frameworks unless explicitly requested
- Change the mental health–focused tone of the content
- Add misleading medical or clinical claims

## Coding Standards
- HTML5 semantic structure
- Pure CSS (no external frameworks)
- Responsive design (mobile-first approach)
- Accessible color contrast and readable typography
- Clean, well-commented code

## Design Principles
- Calm and welcoming visual experience
- Color psychology–based palette
- Minimalistic layout
- Smooth animations only where necessary
- Focus on clarity and emotional comfort

## Content Guidelines
- Supportive and neutral language
- No emojis
- No slang or informal symbols
- Clear headings and readable paragraphs
- Mental-health–safe wording

## File Structure Expectations
- index.html as the main entry point
- Embedded or linked CSS only
- No unnecessary assets or unused files

## Contribution Notes
Anyone contributing to this project must:
- Follow the no-emoji rule strictly
- Maintain accessibility standards
- Preserve the original design intent
- Keep the code simple and readable
